# Revenue Pulse｜广告收入经营分析 PRD

> 版本：v0.3  
> 日期：2026-07-27  
> 状态：已批准  
> 本轮范围：广告收入拆解、经营归因与广告主健康度  
> 明确排除：所有预算指标、预算字段、预算比较和预算结论  
> 公开边界：只有模拟看板可以匿名公开；真实数据及其分析结果不得公开

## 1. 产品定位

Revenue Pulse 面向电商广告业务财务 BP，把“广告收入”这一结果指标拆解为可以归因、可以验证、可以推动经营动作的指标体系。

助手不只回答“收入涨了还是跌了”，还要回答：

1. 变化来自流量、广告位、填充还是价格；
2. 广告收入相对 GMV 的变现效率是否发生变化；
3. 哪种广告形式、流量场景、计费方式、类目或广告主分层贡献了变化；
4. 收入变化是否以用户体验、自然转化或广告主 ROI 恶化为代价；
5. 当前数据能支持哪些结论，哪些指标因缺少数据而不能计算。

## 2. 数据口径原则

### 2.1 不把经营流水自动当作财务收入

系统必须区分：

- 广告消耗：广告主已经实际发生的投放花费；
- 可计费金额：按曝光、点击、转化等计费事件形成的金额；
- 广告经营收入：业务侧用于日常经营监控的收入或流水；
- 月结实际收入：财务系统关账后确认的收入。

只有数据来源和字段含义经过确认后，系统才能显示“广告收入”。如果只有广告消耗、可计费金额或 Sales，必须按原口径展示，不得自动改名为月结实际收入。

### 2.2 不补造缺失数据

- 缺少的指标显示“不可用”及缺失原因；
- 不使用零值代替缺失值；
- 不根据曝光和点击凭空估算财务收入；
- 不根据 GMV 和行业经验值反推收入；
- 外部行业对标必须注明来源、时间、平台范围和口径，没有可靠来源时不输出确定性结论。

### 2.3 完全排除预算

v0.3 不读取、不计算、不展示、不推送以下内容：

- 月度预算；
- 时间进度预算；
- 预算完成率；
- 预测较预算差异；
- 商家申报预算；
- 商家预算利用率；
- 广告预算集中度；
- 预算缺口、预算风险或预算建议。

广告主的“实际广告消耗”不是预算。实际消耗可以作为广告收入来源、广告主 ROI 分母或广告主贡献分析指标继续使用。

## 3. 核心分析模型

### 3.1 流量变现路径

基础公式：

```text
广告收入 = 可商业化流量（VV）× 广告占比（Ad Load）× eCPM ÷ 1,000
```

口径：

- 可商业化流量：具备广告展示机会的 VV；
- Ad Load：广告曝光量 ÷ 可商业化 VV；
- eCPM：广告收入 ÷ 广告曝光量 × 1,000。

当数据能够区分广告请求与实际展示时，将 Ad Load 进一步拆解：

```text
广告曝光量
= 可商业化流量
× 单位流量广告机会数
× 广告请求率
× 填充率
```

这样可以继续判断收入变化来自：

- 可商业化流量变化；
- 广告机会或广告占比变化；
- 填充率变化；
- eCPM 变化。

不得同时使用已经包含填充结果的 Ad Load 和独立填充率重复计算收入。

### 3.2 GMV 变现路径

```text
广告收入 = GMV × 广告货币化率
广告货币化率 = 广告收入 ÷ GMV
```

该路径用于判断：

- 广告收入增长是否只是跟随 GMV 增长；
- 广告变现效率是否提升或下降；
- 哪些类目、场景或广告形式的广告货币化率发生变化。

GMV 和广告收入必须采用相同时间范围、业务范围、币种和统计粒度。

### 3.3 两条路径同时使用

- 流量变现路径定位“量、位、填充、价”；
- GMV 变现路径定位广告收入相对交易大盘的变现效率；
- 两条路径结论冲突时，必须展示口径差异和数据缺口，不强行合并为单一原因。

## 4. 核心指标体系

### 4.1 收入结果层

- 广告收入；
- 广告收入环比、同比；
- 广告收入增长额与增长贡献；
- 广告收入结构占比；
- 月结实际收入与经营口径差异，仅在两类数据同时存在时计算。

### 4.2 流量层

- UV、PV、VV；
- 可商业化 VV；
- 可商业化流量占比；
- 广告曝光量；
- Ad Load；
- 广告请求率；
- 填充率；
- 未填充广告机会。

### 4.3 竞价效率层

- CTR；
- CPC；
- CPM / eCPM；
- 平均竞价出价；
- 有效竞价广告主数；
- 竞价成功率，仅在数据可用时计算。

### 4.4 变现效率层

- 广告 ARPU：广告收入 ÷ 活跃用户数；
- 广告货币化率：广告收入 ÷ GMV；
- 按大盘、类目和流量场景计算的广告货币化率；
- 行业或可比平台对标，仅在存在可靠且口径一致的外部数据时展示。

### 4.5 广告主健康度

- 广告主数量；
- 活跃广告主数量；
- 新增、留存和流失广告主数量；
- 活跃广告主留存率；
- 广告主 ROI：归因 GMV ÷ 实际广告消耗；
- 广告主 ROI 分布；
- 头部广告主收入或实际消耗贡献占比。

本层不包含广告主预算、预算利用率或预算集中度。

### 4.6 用户与自然交易护栏

- 大盘 GMV；
- 自然 GMV 或自然转化率，仅在口径可区分时计算；
- 用户停留时长；
- 页面退出率；
- 广告负反馈或体验指标，仅在数据可用时计算。

护栏用于判断提高 Ad Load 或广告价格是否影响用户体验和自然交易。

## 5. 分析维度

所有可用指标支持按以下维度切分，并比较环比、同比和贡献变化：

- 广告形式：搜索广告、信息流广告、开屏、直播广告、联盟或站外广告；
- 流量场景：首页推荐、搜索结果页、商品详情页、购物车、直播间等；
- 计费方式：CPC、CPM、CPA、ROI 类计费及混合模式；
- 类目或行业；
- 广告主分层：大商家、中小商家、品牌广告主；
- 日期：日、周、月。

数据中不存在的维度不展示空图表。

## 6. 核心分析动作

### 6.1 收入变化归因

对环比、同比收入变化执行两套拆解：

```text
流量变化贡献
+ Ad Load / 广告机会变化贡献
+ 填充率变化贡献
+ eCPM 变化贡献
= 广告收入变化
```

以及：

```text
GMV 变化贡献
+ 广告货币化率变化贡献
= 广告收入变化
```

各项贡献相加后应与实际收入变化一致，允许存在明确标注的四舍五入误差。

### 6.2 供需平衡分析

联合观察：

- Ad Load；
- 填充率；
- 有效竞价广告主数；
- eCPM；
- GMV；
- 用户停留时长；
- 退出率；
- 自然转化。

如果 Ad Load 提升带来短期收入增长，但 GMV、自然转化或用户体验指标明显恶化，系统必须标记为风险，不直接建议继续增加广告位。

### 6.3 广告主 ROI 健康度

追踪广告主 ROI 的中位数、分位数、分层变化和留存关系。

如果收入增长同时伴随广告主 ROI 持续恶化或活跃广告主留存下降，系统应将其标记为收入可持续性风险。

### 6.4 价格与竞价效率分析

在底价、竞价机制或策略发生变化时，比较：

- CPC / eCPM；
- 填充率；
- 有效竞价广告主数；
- 广告主 ROI；
- 收入与 GMV。

没有明确策略事件或实验分组时，只描述相关变化，不输出因果结论。

### 6.5 同行或行业对标

使用广告收入 ÷ GMV 进行可比分析，但必须满足：

- 平台业务模式相近；
- 广告收入与 GMV 口径一致；
- 数据时间接近；
- 来源可追溯。

不把固定区间硬编码为所有电商平台的通用健康标准。

## 7. 数据来源与最小可分析组合

### 7.1 数据来源

- 广告投放日志：请求、曝光、点击、转化、实际消耗、计费方式；
- 竞价日志：出价、参竞广告主、竞价结果、填充；
- 交易系统：GMV、订单、类目和场景；
- 用户行为日志：UV、PV、VV、停留时长、退出和自然转化；
- 广告主数据：广告主状态、分层、活跃和留存；
- 财务系统：月结实际收入、调整、退款和确收；
- 策略事件表：底价、流量策略、广告位或竞价机制变更。

不接入预算表。

### 7.2 数据可用性分级

| 已有数据 | 可以分析 | 不能声称 |
|---|---|---|
| 仅广告日志 | 流量、曝光、CTR、填充、竞价效率 | 广告收入、货币化率、财务收入 |
| 广告日志 + 经营收入或实际消耗 | 流量变现路径、收入变化归因 | 月结实际收入，除非财务确认 |
| 广告收入 + GMV | 广告货币化率及 GMV 路径 | 流量或竞价原因，除非有日志 |
| 广告收入 + GMV + 广告日志 | 两条收入路径及主要经营归因 | 广告主 ROI，除非有归因 GMV |
| 再加广告主与归因数据 | 广告主 ROI、留存和可持续性 | 财务确收差异，除非有月结数据 |
| 再加月结财务数据 | 经营口径与月结实际收入对账 | 未经验证的因果结论 |

## 8. 产品输出

### 8.1 经营概览

- 广告收入及环比、同比；
- 流量、Ad Load、填充率、eCPM；
- GMV 和广告货币化率；
- 广告主 ROI 与活跃广告主；
- 数据截止时间和质量状态。

缺少的 KPI 显示“不可用”，不得用预算类 KPI 填补版面。

### 8.2 归因与下钻

- 收入变化贡献桥；
- 流量变现路径；
- GMV 变现路径；
- 广告形式、场景、计费方式、类目和广告主分层下钻；
- 正向动因、负向动因与风险护栏。

### 8.3 管理层简报

简报必须包含：

1. 广告收入表现及比较期间；
2. 主要增长或下降贡献；
3. 流量、广告位、填充和价格判断；
4. GMV 与广告货币化率判断；
5. 广告主 ROI 和留存风险；
6. 用户体验与自然交易护栏；
7. 数据缺口、口径限制和待验证假设；
8. 可执行的后续核查或经营动作。

简报不得出现预算、预算差异或预算建议。

## 9. 验收标准

- [ ] 核心公式包含正确的 `÷ 1,000` 单位换算；
- [ ] 系统同时支持流量变现路径和 GMV 变现路径；
- [ ] Ad Load 与填充率口径不会重复计算；
- [ ] 环比、同比归因贡献与实际收入变化勾稽一致；
- [ ] 能按可用的广告形式、流量场景、计费方式、类目和广告主分层下钻；
- [ ] 能展示广告主 ROI、活跃和留存，缺失时明确不可用；
- [ ] 能联合 GMV、自然转化和体验指标提示过度商业化风险；
- [ ] 经营收入、实际消耗和月结实际收入具有不同状态标签；
- [ ] 缺少数据时不补零、不反推、不输出确定性结论；
- [ ] 所有指标带定义、公式、期间、来源和数据状态；
- [ ] 所有结论可追溯到指标和数据来源；
- [ ] 页面、Skill、数据管道、管理简报和飞书中均不出现预算指标或预算结论；
- [ ] 模拟数据、测试和公开仓库不包含企业真实数据、个人信息或密钥。

## 10. 本轮不做

- 月度预算管理；
- 预算完成率或预算差异分析；
- 商家预算利用率或预算集中度；
- 自动收入确认或关账；
- 在缺少可靠数据时生成同行结论；
- 无实验或策略事件证据的自动因果判断；
- 自动调整广告位、价格或竞价策略；
- 未经人工审核直接向管理层推送高影响结论。
