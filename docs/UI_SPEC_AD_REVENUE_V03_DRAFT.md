# Revenue Pulse｜广告收入经营分析 UI/UX 规范

> 版本：v0.3  
> 日期：2026-07-27  
> 状态：已批准  
> 对应 PRD：`PRD_AD_REVENUE_V03_DRAFT.md`  
> 适用范围：广告收入数据准备、经营分析、归因下钻、简报审核  
> 明确排除：预算录入、预算指标、预算图表、预算文案  
> 公开边界：只有模拟看板可以匿名公开；真实数据工作区及结果必须受保护

## 1. 体验目标

界面帮助电商广告业务财务 BP 完成：

```text
导入现有数据
→ 确认收入与经营指标口径
→ 判断当前数据能分析什么
→ 同时查看流量变现与 GMV 变现
→ 定位收入变化来自哪里
→ 检查广告主和用户体验风险
→ 审核并分发管理结论
```

设计优先级：

1. 口径可信；
2. 结论可追溯；
3. 变化可归因；
4. 数据缺口可见；
5. 操作高效；
6. 视觉克制。

## 2. 核心设计原则

### 2.1 先确认收入身份，再展示收入

页面必须持续显示当前金额口径：

- `广告经营收入`
- `广告实际消耗`
- `可计费金额`
- `月结实际收入`
- `口径待确认`

只有经过用户确认的财务数据才能显示为“月结实际收入”。其他口径不得通过颜色、缩写或文案暗示为财务确收。

### 2.2 两条分析路径并列

产品不能只展示一个收入总数。经营分析区域必须提供：

- 流量变现：`VV × Ad Load × eCPM`
- GMV 变现：`GMV × 广告货币化率`

两条路径共享同一收入结果、时间范围和筛选条件，但各自显示独立的数据状态和缺口。

### 2.3 状态先于图表

每个指标、图表和结论都带状态：

- `可用`
- `质量警告`
- `不可用`
- `口径待确认`
- `质量阻断`

不可用时显示缺失字段或缺失数据源，不用 `0`、空白或孤立的 `—` 代替。

### 2.4 不用复杂视觉掩盖事实

- 企业分析工具采用高密度、低装饰的视觉方向；
- 结论、数值、比较期间和来源优先；
- 动画只用于加载、展开和状态变化；
- 图表必须有数据表或列表替代；
- 不使用 3D 图、仪表盘、雷达图或装饰性大数字背景。

### 2.5 无预算

页面不提供：

- 预算上传入口；
- 预算字段映射；
- 预算完成率；
- 预测较预算差异；
- 预算趋势线；
- 预算差异桥；
- 商家预算利用率；
- 预算风险和预算建议。

如果上传文件中识别到疑似预算字段，映射页显示：

```text
已识别为预算字段
本版本不使用预算数据，该字段不会进入分析。
```

用户可以将其保留为“忽略字段”，无需删除原文件。

## 3. 信息架构

### 3.1 全局导航

```text
Revenue Pulse
数据准备｜经营概览｜收入归因｜广告主健康｜数据质量｜指标口径｜管理简报
```

全局导航右侧固定显示：

- 收入口径；
- 数据截止时间；
- 比较期间；
- 数据质量状态；
- `导入新数据`；
- `生成分析`。

移动端折叠为顶部菜单，但必须在首屏保留收入口径、截止时间和质量状态。

### 3.2 页面结构

产品包含七个工作区：

1. 数据导入；
2. 数据源分类与字段映射；
3. 数据可用性与质量；
4. 经营概览；
5. 收入归因与维度下钻；
6. 广告主健康与体验护栏；
7. 管理简报审核与推送。

## 4. 数据准备流程

### 4.1 步骤导航

数据准备使用可回退的步骤条：

```text
1 上传文件
→ 2 确认数据源
→ 3 映射字段
→ 4 检查可用性
→ 5 生成分析
```

已完成步骤可返回修改。修改字段映射后，旧分析结果标记为“需要重新生成”。

### 4.2 数据导入空状态

标题：

```text
先看看你手里有哪些广告经营数据
```

说明：

```text
上传 CSV 或 Excel。系统会先识别收入、流量、广告投放、GMV、
广告主和月结数据，不会把 Sales 或广告消耗自动当作财务收入。
```

操作：

- 主按钮：`选择文件`
- 次按钮：`使用模拟数据体验`
- 显示支持格式、大小限制、隐私说明；
- 拖拽区和按钮均支持键盘。

### 4.3 数据源分类

每个文件使用卡片确认数据源角色：

- 广告收入或实际消耗；
- 广告曝光与点击；
- 广告请求与填充；
- 竞价日志；
- GMV 与订单；
- 用户行为；
- 广告主主数据与状态；
- 广告主归因 GMV；
- 月结财务收入；
- 策略事件；
- 其他；
- 忽略。

一个文件可以包含多个角色，但界面应提示粒度和主键冲突风险。

### 4.4 字段映射表

| 原字段 | 样例值 | 系统推断 | 置信度 | 用户确认 | 状态 |
|---|---|---|---|---|---|

优先识别：

- 日期和时间；
- 收入或实际消耗；
- 收入口径；
- 广告曝光、请求、填充、点击、转化；
- UV、PV、VV、可商业化 VV；
- GMV、订单；
- 广告主 ID 和分层；
- 广告形式、流量场景、计费方式、类目；
- 出价、参竞广告主、竞价结果；
- 停留时长、退出和自然转化；
- 策略事件；
- 唯一键和关联键。

预算字段只能映射为“忽略”，不能进入候选业务指标。

### 4.5 收入口径确认

这是生成分析前的必填项，使用单选卡：

- 广告经营收入；
- 广告实际消耗；
- 可计费金额；
- 月结实际收入；
- 其他；
- 当前无法确认。

每个选项展示：

- 定义；
- 适合回答的问题；
- 不能声称的内容。

选择“月结实际收入”时，额外要求确认来源系统和结账月份。

### 4.6 映射交互

- 系统推断仅作为建议，用户确认优先；
- 必填项在对应行就地报错；
- 支持批量确认高置信度字段；
- 支持搜索、筛选未确认字段；
- 离开页面保留映射进度；
- 主要按钮：`确认映射并检查数据`；
- 错误使用 `role="alert"` 或 `aria-live`。

## 5. 数据可用性与质量

### 5.1 顶部摘要

展示：

- 收入口径；
- 时间范围；
- 数据粒度；
- 数据质量：`通过 / 警告 / 阻断`；
- 可用分析路径：`流量变现 / GMV 变现`；
- 可用维度数量；
- 缺失数据数量。

### 5.2 两条路径可用性

使用两个并列状态卡。

#### 流量变现路径

```text
广告收入
= 可商业化 VV
× Ad Load
× eCPM
÷ 1,000
```

每个因子显示：

- 可用状态；
- 对应字段；
- 时间范围；
- 粒度；
- 质量问题。

如果数据区分请求和填充，则在 Ad Load 下展开：

```text
广告机会数 → 请求率 → 填充率 → 广告曝光
```

#### GMV 变现路径

```text
广告收入 = GMV × 广告货币化率
```

分别显示收入和 GMV 的业务范围、币种、期间是否一致。

### 5.3 分析能力清单

分成三组：

#### 可以分析

例如：

- 广告收入趋势；
- 流量变现拆解；
- 搜索与信息流贡献。

#### 补充数据后可以分析

例如：

- 补充 GMV 后可以计算广告货币化率；
- 补充广告请求后可以区分请求率和填充率；
- 补充归因 GMV 后可以计算广告主 ROI。

#### 当前不能分析

例如：

- 没有月结财务数据，不能显示月结实际收入；
- 没有用户行为数据，不能判断广告位变化对体验的影响。

### 5.4 质量阻断

以下情况阻断相关路径：

- 收入口径未确认；
- 收入、GMV 或流量期间不一致且无法对齐；
- 关键字段大量缺失；
- 重复主键导致金额或曝光重复；
- 收入与曝光单位无法确认；
- Ad Load 与填充率存在重复计算风险；
- 数据源时间延迟超过已确认 SLA。

阻断卡显示原因、受影响指标、文件、字段和修复动作。只阻断受影响的路径，不影响其他独立可用分析。

## 6. 经营概览

### 6.1 首屏上下文条

任何截图、导出或复制内容都必须带：

```text
口径：广告经营收入
期间：2026-07-01 至 2026-07-25
对比：去年可比期间
范围：全站广告
质量：警告
```

### 6.2 KPI 区

桌面首屏最多显示六张核心卡：

1. 广告收入；
2. 收入同比或环比；
3. 可商业化 VV；
4. Ad Load；
5. eCPM；
6. 广告货币化率。

卡片结构：

- 指标名称；
- 业务状态；
- 主数值；
- 对比变化；
- 时间范围；
- 数据来源图标或文字；
- `查看口径`。

GMV 不可用时，广告货币化率卡片保留并显示：

```text
不可用
缺少同范围 GMV
```

不得改用预算指标填补该位置。

### 6.3 经营结论卡

KPI 下方显示最多三条：

- 最大正向贡献；
- 最大负向贡献；
- 最重要的可持续性风险。

每条结论带：

- `事实 / 判断 / 风险` 标签；
- 影响金额或比例；
- 来源入口；
- 待验证状态。

没有足够证据时显示“当前无法确定主要原因”，不生成完整但虚假的叙述。

### 6.4 收入趋势

默认展示广告收入日趋势：

- 本期：深蓝实线；
- 可比期：中性灰虚线；
- 月结实际收入：仅在存在时使用深绿色实线；
- 经营口径与月结口径不可直接连接成同一条线。

提供：

- 日 / 周 / 月切换；
- 累计 / 单日切换；
- 环比 / 同比切换；
- 键盘可访问的数据点；
- 同内容数据表；
- 导出 CSV。

不显示预算线。

## 7. 双路径收入分析

### 7.1 路径切换

使用页签：

```text
流量变现｜GMV 变现
```

两个页签显示各自状态：

- `可用`
- `部分可用`
- `不可用`

切换页签时保留全局筛选条件和比较期间。

### 7.2 流量变现页

顶部使用公式因子卡：

```text
可商业化 VV
× Ad Load
× eCPM
÷ 1,000
= 广告收入
```

每个因子卡显示：

- 本期值；
- 对比变化；
- 对收入变化的贡献；
- 数据质量；
- 下钻入口。

如果存在请求与填充数据，可展开为线性漏斗：

```text
广告机会 → 广告请求 → 成功填充 → 广告曝光 → 点击 → 收入
```

每一步显示数量、转化率和流失量。漏斗提供同内容线性列表。

### 7.3 流量路径贡献桥

使用瀑布图表示：

```text
上期收入
→ 流量变化
→ Ad Load / 广告机会变化
→ 填充变化
→ eCPM 变化
→ 本期收入
```

规则：

- 项目控制在 4–12 个；
- 增加、减少除颜色外同时使用方向箭头和正负号；
- 每个项目显示影响金额；
- 提供包含运行累计值的数据表；
- 贡献和本期收入变化必须勾稽。

### 7.4 GMV 变现页

顶部使用公式因子卡：

```text
GMV
× 广告货币化率
= 广告收入
```

下方展示：

- GMV 与广告收入双趋势；
- 广告货币化率趋势；
- GMV 变化贡献与货币化率变化贡献；
- 按类目和场景的广告货币化率排行。

GMV 与收入口径不一致时，页面顶部显示持续警告，不输出整体广告货币化率。

## 8. 维度下钻

### 8.1 全局筛选

只显示数据中可用的筛选项：

- 日期；
- 广告形式；
- 流量场景；
- 计费方式；
- 类目或行业；
- 广告主分层。

已选筛选条件显示为可移除标签，并提供 `清除全部`。筛选状态应进入页面链接，便于分享和复查。

### 8.2 贡献排行

默认使用排序表和横向条形图，按以下维度切换：

- 广告形式；
- 流量场景；
- 计费方式；
- 类目；
- 广告主分层。

每行显示：

- 本期收入；
- 环比或同比；
- 收入变化贡献；
- Ad Load；
- eCPM；
- 广告货币化率；
- 数据状态；
- 查看证据。

当前不可用的列显示缺失原因。超过 15 个分类时默认显示 Top 10、Bottom 5 和可搜索全表。

### 8.3 下钻交互

点击一行后：

- 将该维度加入筛选；
- 刷新两条收入路径；
- 保留面包屑；
- 显示当前范围；
- 支持一步返回上一层。

不得用只能悬停触发的下钻。

## 9. 广告主健康

### 9.1 KPI

- 活跃广告主数；
- 新增广告主数；
- 留存率；
- 流失广告主数；
- 广告主 ROI 中位数；
- ROI 低于已确认警戒线的广告主占比。

没有归因 GMV 时，ROI 指标显示不可用，但活跃和留存仍可独立展示。

### 9.2 ROI 分布

优先使用分布柱状图或分位数表：

- P25；
- 中位数；
- P75；
- 不同广告主分层；
- 本期与可比期。

不只展示平均 ROI，避免头部广告主掩盖长尾恶化。

### 9.3 留存与贡献

展示：

- 活跃、新增、留存、流失的数量变化；
- 不同分层收入或实际消耗贡献；
- 头部广告主贡献占比；
- ROI 变化与留存变化的并列比较。

本页不展示预算或预算集中度。

## 10. 用户体验与自然交易护栏

使用紧凑状态表：

| 护栏指标 | 本期 | 对比变化 | 状态 | 与收入变化关系 |
|---|---:|---:|---|---|
| GMV |  |  |  |  |
| 自然转化率 |  |  |  |  |
| 用户停留时长 |  |  |  |  |
| 页面退出率 |  |  |  |  |
| 广告负反馈 |  |  |  |  |

如果 Ad Load 或 eCPM 提升同时伴随护栏明显恶化，显示风险卡：

```text
收入增长可能伴随用户体验或自然交易压力
```

如果只有同期变化而没有实验或策略事件，使用“同时发生”“相关变化”，不得使用“导致”。

## 11. 指标口径与证据

### 11.1 证据抽屉

点击 KPI、图表项目或结论后，从右侧打开：

- 指标定义；
- 公式；
- 单位；
- 时间范围；
- 业务范围；
- 数据来源；
- 使用字段；
- 更新时间；
- 质量限制；
- 关联结论；
- 复制证据链接。

抽屉打开后焦点进入抽屉；关闭后返回触发按钮；支持 `Esc`。

### 11.2 公式展示

流量路径必须显示单位换算：

```text
收入 = VV × Ad Load × eCPM ÷ 1,000
```

如果 Ad Load 已包含实际曝光结果，证据抽屉明确说明填充率不再重复相乘。

### 11.3 证据类型

每条结论标记：

- `事实`
- `判断`
- `风险`
- `待验证`

没有数据支持的建议不能标记为事实。

## 12. 管理简报审核与推送

简报按以下顺序：

1. 广告收入表现；
2. 流量变现归因；
3. GMV 变现归因；
4. 主要维度贡献；
5. 广告主 ROI 与留存；
6. 用户体验和自然交易风险；
7. 数据限制；
8. 建议核查和经营动作。

简报中不得出现预算、预算完成率、预算差异或预算建议。

### 12.1 人工确认

推送前显示：

- 收入口径；
- 数据截止时间；
- 比较期间；
- 数据质量；
- 接收渠道；
- 简报全文；
- `我已核对关键指标、收入口径和数据限制`；
- `确认并推送`。

未勾选时按钮不可用。推送成功或失败必须显示时间、渠道、结果和重试入口。

## 13. 页面状态

| 状态 | 界面行为 |
|---|---|
| 无数据 | 显示数据导入引导 |
| 解析中 | 固定高度骨架屏和进度说明 |
| 需要分类 | 聚焦未确认的数据源角色 |
| 需要映射 | 聚焦未确认字段 |
| 收入口径待确认 | 阻断收入结论 |
| 质量通过 | 允许生成分析 |
| 质量警告 | 允许生成，但持续显示警告 |
| 局部路径阻断 | 只阻断对应路径 |
| 全局质量阻断 | 不生成确定性管理结论 |
| 指标不可用 | 显示缺失数据和补充建议 |
| 疑似预算字段 | 标记忽略，不进入分析 |
| 无月结数据 | 显示“尚无月结实际收入” |
| 结果需重算 | 保留旧结果并提示重新生成 |
| 请求失败 | 保留输入、就地报错和重试 |
| 推送成功 | 显示时间、渠道和结果 |

## 14. 视觉系统

### 14.1 视觉方向

- 风格：企业经营分析、可信、克制、高信息密度；
- 保留当前深蓝、白色和中性灰基础；
- 不采用夸张大标题或营销落地页式留白；
- 通过排版层级、分组、边框和状态标签组织复杂信息；
- 不使用 emoji 作为功能图标。

### 14.2 颜色

| 用途 | 色值 |
|---|---|
| 主品牌/主要操作 | `#1E40AF` |
| 交互高亮 | `#2563EB` |
| 强调/待处理 | `#B45309` |
| 页面背景 | `#F8FAFC` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#172033` |
| 次文字 | `#5F6B7A` |
| 边框 | `#DCE3EC` |
| 正向 | `#047857` |
| 警告 | `#B45309` |
| 阻断/负向 | `#B91C1C` |

颜色使用语义变量，不能散落在组件中。正向、负向、警告和阻断必须同时使用文字、符号或图标表达。

### 14.3 字体和数字

优先使用系统字体：

```text
-apple-system, BlinkMacSystemFont, "Segoe UI",
"PingFang SC", "Microsoft YaHei", sans-serif
```

- 正文不小于 14px；
- 关键解释不小于 13px；
- 表格辅助信息不小于 12px；
- 正文行高不低于 1.5；
- 金额、百分比和日期使用等宽数字特性；
- 不额外加载网络字体，保证企业环境稳定性。

### 14.4 间距与尺寸

- 基础间距：4px；
- 常用间距：8、12、16、24、32px；
- 卡片圆角：12px；
- 表单和按钮圆角：8px；
- 点击区域最小 44×44px；
- 相邻点击目标至少间隔 8px；
- 主内容最大宽度 1440px；
- 图表异步加载时预留固定高度，避免布局跳动。

### 14.5 动效

- 使用 150–250ms 状态过渡；
- 只用于加载、切换、展开和筛选反馈；
- 不使用滚动入场、数字翻滚或装饰性漂浮；
- 遵守 `prefers-reduced-motion`。

- 主趋势与经营结论双栏；
- 下钻表与证据视图可以并排；

## 16. 可访问性

- 正文对比度至少 4.5:1；
- 所有功能支持键盘；
- 保留清晰焦点环；
- 图标按钮具有可访问名称；
- 标题层级连续；
- 错误使用 `role="alert"` 或 `aria-live`；
- 状态不只依赖颜色；
- 图表提供数据表或线性列表；
- 表单使用可见标签；
- 模态框和抽屉正确管理焦点；
- 页面不禁止缩放；
- 支持减少动画偏好；
- 下钻、展开和页签状态可被屏幕阅读器识别；
- 数据表包含表头、排序状态和当前筛选范围。

## 17. UI 验收标准

- [ ] 新用户可以完成文件上传、数据源分类和字段映射；
- [ ] 用户必须确认收入口径后才能生成收入结论；
- [ ] 预算字段只能被忽略，界面无预算入口、指标、图表和文案；
- [ ] 首屏显示广告收入、流量、Ad Load、eCPM 和广告货币化率；
- [ ] 流量变现和 GMV 变现均有独立状态与缺失说明；
- [ ] Ad Load 与填充率的关系在界面和证据中清晰；
- [ ] 流量路径贡献桥与收入变化勾稽；
- [ ] 支持按广告形式、场景、计费方式、类目和广告主分层下钻；
- [ ] 广告主健康同时展示 ROI 分布和留存，不只展示平均值；
- [ ] 用户体验与自然交易护栏可以提示过度商业化风险；
- [ ] 指标、结论和图表都能打开口径与证据；
- [ ] 数据缺失时显示原因，不补零、不展示误导性空图；
- [ ] 推送前必须人工确认收入口径和数据限制；
- [ ] 图表不只依赖颜色，且有表格或列表替代；
- [ ] 375、768、1024、1440px 无页面级横向溢出；
- [ ] 键盘可以完成核心流程；
- [ ] 主要点击区域不小于 44×44px；
- [ ] 异步内容不会造成明显布局跳动。

## 18. 待批准的设计决策

1. 保留当前深蓝、白色和中性灰的企业分析风格；
2. 桌面首屏使用六张核心 KPI 卡；
3. 流量变现与 GMV 变现使用页签切换；
4. 流量路径使用公式因子卡、线性漏斗和贡献瀑布图；

6. 广告主 ROI 使用分位数和分布，不只显示平均值；
7. 缺失指标保留位置并显示原因；
8. 局部数据问题只阻断对应分析路径；
9. 预算字段只显示为“忽略”，不进入任何分析；
10. 管理简报推送前必须人工审核。
