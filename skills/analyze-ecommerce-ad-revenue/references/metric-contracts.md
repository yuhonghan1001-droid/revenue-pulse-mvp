# 指标口径

没有公司正式口径时，使用以下定义。如果公司已有批准口径，明确说明差异，并确保实际、同期、预算和预测采用同一套定义。

## 核心指标

### 经营流水收入

- 定义：有效广告投放产生的、扣除返点和退款前的广告计费金额。
- 公式：有效计费交易金额之和。
- 基础粒度：日期 × 商家 × 广告产品 × 流量来源。
- 禁止把经营流水收入直接称为财务确收收入或净收入。

### 计费确认收入

- 定义：由计费或结算系统确认的毛收入。
- 公式：截至数据截止时间的计费确认金额之和。
- 必须与经营流水收入对账，并解释时间、业务范围或政策差异。

### 净收入

- 定义：计费确认毛收入扣除返点和退款后的收入。
- 公式：计费确认收入 − 返点 − 退款。
- 正负号：来源表中的返点和退款使用正数记录，计算净收入时予以扣减。
- 作为 Revenue Pulse MVP 的默认头部收入指标。

### 去年同期可比净收入

- 定义：与当前已过期间具有经济可比性的去年同期净收入。
- 匹配已过天数；差异较大时，还要匹配星期结构、大促阶段、节假日位置和政策范围。
- 如果只能使用相同自然日期，明确标注“自然日同比”。

### 收入同比

- 公式：当前可比净收入 ÷ 去年同期可比净收入 − 1。
- 如果业务范围或期间不可比，返回“不可比”，不要强行给出百分比。

### 时间进度预算

- 定义：按照批准的收入节奏曲线，分摊到数据截止时间的月度预算。
- 没有正式节奏曲线时，可以使用直线进度，但必须标注为临时假设。

### 预算达成率

- 截至当前预算达成率：实际净收入 ÷ 时间进度预算。
- 预计全月预算达成率：月末预测 ÷ 全月预算。
- 禁止在不说明的情况下，用月中实际收入直接除以全月预算。

### 月末收入预测

- 定义：截至当前的实际净收入，加上剩余期间的预计净收入。
- 最低限度假设：近期运行速度或模型基线、日历与大促影响、已知策略变化、返点和退款预期。
- 保留预测版本、运行时间、关键假设和人工调整记录。

### 预测差异

- 预测较预算差异：月末预测 ÷ 全月预算 − 1。
- 预测较上一版差异：最新预测 ÷ 上一版预测 − 1。
- 管理层询问“预期是否变化”时，同时报告这两项差异。

### 返点率

- 公式：返点金额 ÷ 计费确认收入。
- 数据允许时，区分合同返点、专项激励和返货或流量补偿。

### 商家预算利用率

- 公式：有效广告消耗或经营流水收入 ÷ 商家申报广告预算。
- 不要把商家的广告投放预算与平台内部费用预算混为一谈。

## 指标必备信息

每个管理指标都要保留：

| 字段 | 要求 |
|---|---|
| `metric_id` | 稳定、可供程序使用的指标 ID |
| `name` | 面向使用者的指标名称 |
| `definition` | 业务含义 |
| `formula` | 可复算公式 |
| `grain` | 计算粒度 |
| `cutoff` | 数据截止时间 |
| `source_ids` | 稳定的数据源 ID |
| `owner` | 业务或财务负责人 |
| `reconciliation` | 对账状态和差异解释 |

## 比较护栏

- 确保比较双方使用相同收入范围以及相同毛收入或净收入口径。
- 分开量化规模、价格、结构、返点和退款影响。
- 会计、产品或策略发生重大变化后，重新建立可比基准。
- 不直接对多个分组百分比求平均；先汇总分子和分母，再计算比例。
- 计算时保留足够精度，只在展示阶段四舍五入。
